# Examples

Four consumer applications that import only the public API of @baehaqirafly3/bot-wa.

- echo-bot: one command that echoes its arguments
- group-manager-bot: group only scope with the anti link middleware
- ai-chatbot: command skeleton wired to an LLM provider URL from env
- multi-session-bot: two sessions in one process

Run any example with npm start inside its folder after installing workspace dependencies.
